# Markdown ファイルの仕様

## front matter（オプション）

Markdown ファイルの先頭に YAML front matter を記載することで、JXls テンプレート内の変数名やユーザ定義変数を指定できます。

```markdown
---
spec_var: loginSpec
feature: ログイン
viewpoint: 正常系
---

# ログイン仕様書
```

| キー | 種別 | 説明 |
|---|---|---|
| `spec_var` | 予約キー | JXls テンプレート内で使用する変数名。未指定の場合はファイル名（拡張子なし）が使用される。 |
| `spec_*` | 予約プレフィックス | `spec_` で始まるキーはすべて予約済み。ユーザ定義変数には使用不可。 |
| その他のキー | ユーザ定義変数 | テンプレートから `${varName.vars['キー名']}` で参照できる。 |

> **例:** `spec_var: loginSpec` と指定すると、テンプレート内で `${loginSpec.title}` のように参照できます。  
> `feature: ログイン` を定義した場合は `${loginSpec.vars['feature']}` で参照できます。

### `spec_var` に指定できる文字

`spec_var` の値は **Java / JEXL の識別子**として有効な文字列を指定してください。

- 使用できる文字：英字（`a`〜`z`, `A`〜`Z`）、数字（`0`〜`9`）、アンダースコア（`_`）、ドル記号（`$`）
- 先頭は英字またはアンダースコアにしてください（数字から始めることはできません）
- **日本語・空白・ハイフン（`-`）などは使用できません**

**推奨命名規則:**

| スタイル | 例 |
|---|---|
| camelCase（推奨） | `loginSpec`, `userRegistration` |
| snake_case | `login_spec`, `user_registration` |

> JXls の式エンジン（JEXL）の詳細は [JXls 公式ドキュメント](https://jxls.sourceforge.net/) を参照してください。

## 全体構造

| Markdown 要素 | 対応するフィールド | 説明 |
|---|---|---|
| `# 見出し 1` | タイトル (`title`) | テスト仕様書全体のタイトル |
| `## 見出し 2` | 大項目 (`mainItem`) | テストケースの大分類 |
| `### 見出し 3` | 中項目 (`middleItem`) | テストケースの中分類 |
| `#### 見出し 4` | 小項目 (`smallItem`) | テストケースの小分類 |
| 順序付きリスト | 確認手順 (`steps`) | 実行する操作手順 |
| チェックリスト（箇条書き） | 想定動作 (`expected`) | 期待される動作・結果 |
| コードブロック | 備考 (`notes`) | 補足情報・注意事項 |
| 3列テーブル | カスタム変数 (`customFields`) | 任意のケース属性（後述） |

## カスタム変数テーブル（オプション）

各テストケース内で次の 3 列テーブルを使うと、任意のカスタム変数を定義できます。

| 論理名 | 変数名 | 値 |
|---|---|---|
| 優先度 | priority | High |
| テスター | tester_id | user123 |

- テーブル位置はテストケース内のどこでも構いません。
- 1 ケース内に複数テーブルがある場合はマージされ、同じ `変数名` は後ろの値で上書きされます。
- テーブルがないケースでも問題ありません（`customFields` は空になります）。
- `変数名` は Java/JEXL 識別子として有効な値（英数字、`_`、`$`）を使用してください。

## テストケースの区切り

1つのテストケースは **確認手順（順序付きリスト）** と **想定動作（チェックリスト）** を
1セットとして構成されます。次の見出し（`##`〜`####`）が現れた時点で、それまでの手順・想定動作・備考をまとめた
テストケースが確定します。

## 記載例

```markdown
# テストケース名

## 大項目１

### 中項目１

#### 小項目１

1. 確認手順 1
1. 確認手順 2

- [ ] 想定動作 1
- [ ] 想定動作 2

\`\`\`text
備考１
備考２
\`\`\`

### 中項目２

#### 小項目１

1. 確認手順 A
1. 確認手順 B

- [ ] 想定動作 A
- [ ] 想定動作 B
```

## 注意事項

- front matter の `spec_var` キーで JXls テンプレート内の変数名を指定できます（推奨）。
  `spec_var` が未指定の場合はファイル名（拡張子なし）が変数名として使用されます。
- front matter で `spec_` プレフィックス以外のキーを記載するとユーザ定義変数として扱われ、テンプレートから `${varName.vars['キー名']}` で参照できます。
- `spec_` で始まるキーはすべて予約済みのため、ユーザ定義変数のキーには使用しないでください。
- 確認手順は **順序付きリスト**（`1. テキスト` 形式）で記載してください。
  - 手順項目内で継続行を書く場合は、2 文字以上のインデントを付けてください。継続行は同一手順として扱われ、出力時は先頭行の `1. ` に揃えて **3 スペース**の固定インデントでセル内改行されます。
- 想定動作は **チェックリスト形式の箇条書き**（`- [ ] テキスト` 形式）で記載してください。
  - 箇条書き項目内で継続行を書く場合は、2 文字以上のインデントを付けてください。継続行は同一項目として扱われ、出力時もセル内改行＋インデントが維持されます。
- 備考は **コードブロック**（`` ``` `` で囲まれた範囲）で記載してください。言語指定は任意です。
- 備考が不要なテストケースはコードブロックを省略できます。
- カスタム変数を使う場合は 3 列（`論理名`・`変数名`・`値`）のテーブルで記載してください。

## 入出力の例

### ① Markdown ファイル（`mdSpec.md`）

```markdown
# ログイン機能テスト

## 正常系

### パスワード認証

#### 正しいID/パスワードでログイン

1. ブラウザでログイン画面を開く
1. 正しいIDとパスワードを入力する
1. ログインボタンを押す

- [ ] ホーム画面が表示される
- [ ] ユーザー名がヘッダーに表示される

\`\`\`text
事前条件: テストユーザーが登録済みであること
\`\`\`

## 異常系

### パスワード認証

#### 誤ったパスワードでログイン

1. ブラウザでログイン画面を開く
1. 正しいIDと誤ったパスワードを入力する
1. ログインボタンを押す

- [ ] エラーメッセージが表示される
- [ ] ログイン画面に留まる
```

このファイルを変換すると、以下のように **2行のテストケース** が生成されます。

### ② 変換後のテストケースデータ

| フィールド | テストケース 1 | テストケース 2 |
|---|---|---|
| 大項目 | 正常系 | 異常系 |
| 中項目 | パスワード認証 | パスワード認証 |
| 小項目 | 正しいID/パスワードでログイン | 誤ったパスワードでログイン |
| 確認手順 | 1. ブラウザでログイン画面を開く<br>2. 正しいIDとパスワードを入力する<br>3. ログインボタンを押す | 1. ブラウザでログイン画面を開く<br>2. 正しいIDと誤ったパスワードを入力する<br>3. ログインボタンを押す |
| 想定動作 | ・ホーム画面が表示される<br>・ユーザー名がヘッダーに表示される | ・エラーメッセージが表示される<br>・ログイン画面に留まる |
| 備考 | 事前条件: テストユーザーが登録済みであること | （なし） |

### ③ 出力 Excel のイメージ

```
| No | 大項目 | 中項目         | 小項目                        | 確認手順         | 想定動作                       | 備考                          |
|----|--------|----------------|-------------------------------|------------------|-------------------------------|-------------------------------|
|    | 正常系 | パスワード認証  | 正しいID/パスワードでログイン  | 1. ブラウザで... | ・ホーム画面が表示される        | 事前条件: テストユーザーが... |
|    | 異常系 | パスワード認証  | 誤ったパスワードでログイン     | 1. ブラウザで... | ・エラーメッセージが表示される  |                               |
```

> 実際の出力レイアウトはテンプレート Excel の設計に依存します。  
> リポジトリに同梱の `template/template.xlsx` と `example/` を参考にしてください。
